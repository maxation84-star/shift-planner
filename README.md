# 근무표 플래너

직원 휴무·연차와 객실 상태(연박·공사·공실)를 달력에 넣고, 이번 달 휴무를 몇 번 썼고 몇 번 남았는지 바로 보는 웹앱입니다.
로그인 없이 링크만으로 열리고, 폰에서는 "홈 화면에 추가"로 앱처럼 설치됩니다.

**앱 주소**: https://maxation84-star.github.io/shift-planner/

## 기능

- **달력**: 일·월·화·수·목·금·토 순서, 일요일 빨강·토요일 파랑, 오늘 표시.
- **휴무 입력**: 날짜를 누르면 직원별로 `근무 / 휴무 / 연차 / 추가` 선택. "빠른 입력"에서 이름을 고르면 날짜 탭만으로 입력.
- **객실 상태**: 날짜마다 `연박 / 공사 / 공실` 표시 + 짧은 메모.
- **집계**: 직원별 휴무 사용/기본, 남은 휴무, 연차 사용/남음, 추가휴무, 합계, 쉬는 날짜. 월 전체 합계. 직원별 한눈에 표.
- **직원 관리**: 이름·색 변경, 추가·삭제. 근무형태 **주6일(월 휴무 4회)** / **주5일(월 휴무 8회)**, 월 연차 1회.
- **자동 배정**: 기본 휴무를 고르게 배치. 같은 날 인원 고르게, 하루 최대 휴무 인원, 금·토 피하기, 공사일 몰아주기.
- **공유**: 이번 달 달력을 **이미지(PNG)** 로 만들어 카톡 등으로 바로 보내기 또는 저장. 글로 공유·복사도 가능.
- **색**: 직원 색은 파스텔 12색 중 고를 수 있습니다(직원 관리).
- **자동 백업**: 바꿀 때마다 기기에 자동 저장 + 최근 40개 시점 기록, 원하는 시점으로 되돌리기. 파일로 저장/불러오기, 백업 파일 카톡 공유, 텍스트 복사.
- **공유 저장소**: 버튼 하나로 계정 없이 공유하거나, Firebase 실시간 DB를 연결해 링크를 아는 모든 사람이 같은 달력을 봅니다(아래 설정).

## 다같이 쓰기 ① — 계정 없이 (가장 쉬움, 1분)

1. 앱을 열고 **🔗 공유 설정** → **계정 없이 공유 시작** 버튼을 누릅니다. 지금 달력 내용이 그대로 올라갑니다.
2. 다시 **🔗 공유 설정**을 열면 **편집 링크**(쓰기 키 포함)와 **보기 전용 링크**가 나옵니다. 편집 링크는 입력 담당자에게, 보기 링크는 직원들에게 보내세요.
3. 15초마다 자동으로 새로 고쳐지고, 입력하면 바로 올라갑니다.

무료 외부 JSON 저장 서비스(extendsclass, 안 되면 jsonblob)를 씁니다. 오래 안 쓰면 지워질 수 있으니 월말마다 **백업**을 눌러 복사해 두세요. 링크를 아는 사람만 접근할 수 있습니다.

## 다같이 쓰기 ② — Firebase (더 안정적, 약 5분)

Firebase 무료 요금제(Spark)로 충분합니다. 신용카드 필요 없습니다.

1. https://console.firebase.google.com 접속 → 구글 계정 로그인 → **프로젝트 추가** → 이름 아무거나(예: 근무표) → 애널리틱스는 꺼도 됨 → 만들기.
2. 왼쪽 메뉴 **빌드 → Realtime Database** → **데이터베이스 만들기** → 위치는 `asia-southeast1`(싱가포르) → **테스트 모드**로 시작.
3. **규칙(Rules)** 탭을 열고 아래 내용으로 바꾼 뒤 **게시**:
   ```json
   {
     "rules": {
       "boards": {
         "$board": { ".read": true, ".write": true }
       }
     }
   }
   ```
   `boards` 아래 경로만 읽기/쓰기가 되고, 경로 이름을 아는 사람만 접근할 수 있습니다. 경로 이름은 추측하기 어렵게 지으세요.
4. **데이터** 탭 위에 보이는 주소를 복사합니다. 예: `https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app`
5. 앱을 열고 **🔗 공유 설정** → 주소 뒤에 `/boards/원하는이름` 을 붙여서 넣고 **연결**.
   예: `https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app/boards/moza-2026-x7k2`
6. 다시 **🔗 공유 설정**을 열면 두 가지 링크가 나옵니다.
   - **편집 링크**: 입력 담당자에게
   - **보기 전용 링크**: 직원들에게 (화면에서 입력만 막는 것이라, 편집 링크를 아는 사람은 누구나 고칠 수 있습니다)

링크를 한 번 열면 그 기기에 저장소 주소가 기억되므로, 홈 화면에 추가한 뒤에는 아이콘만 눌러도 공유 달력이 열립니다.

## 혼자 쓰기

공유 설정을 하지 않으면 브라우저(그 기기)에만 저장됩니다. 다른 기기로 옮길 때는 **백업**에서 복사 → 붙여넣기.

## 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 파일을 `gh-pages` 브랜치로 복사하고, GitHub Pages가 그 브랜치를 배포합니다.
배포가 안 되면 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: gh-pages / (root)** 로 한 번만 맞춰 주세요.

## 데이터 구조

```json
{
  "version": 1,
  "people": [{ "id": "p1", "name": "홍기범", "color": "#2563eb", "work": "w6", "baseOff": 4, "annual": 1 }],
  "days": { "2026-10-05": { "off": { "p1": "off" }, "tags": ["stay"], "memo": "공실 3" } }
}
```

`work`: `w6`(주6일) · `w5`(주5일). `off` 값: `off`(휴무) · `annual`(연차) · `extra`(추가휴무). `tags`: `stay`(연박) · `work`(공사) · `empty`(공실).
